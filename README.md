## Descripción del Proyecto
Este repositorio contiene la solución a los cinco ejercicios de Programación Orientada a Objetos (POO) del Capítulo 6 desarrollados en **Python** utilizando la librería gráfica `tkinter`:

1. **Ejercicio 6.4 (Página 400):** Manejo de excepciones (`try-except-finally`) mediante la clase `PruebaExcepciones` para capturar errores de división por cero y referencias nulas.
2. **Ejercicio 6.5 (Página 406):** Lanzamiento explícito de excepciones (`raise`) mediante la clase `Vendedor` para validar restricciones de edad.
3. **Ejercicio 6.6 (Página 412):** Captura de múltiples excepciones (`catchs` múltiples) mediante la clase `CálculosNuméricos` para calcular el logaritmo neperiano y la raíz cuadrada.
4. **Ejercicio 6.7 (Página 418):** Validación de campos de entrada y control de capacidad de integrantes mediante las clases `EquipoMaratónProgramación` y `Programador`.
5. **Ejercicio 6.8 (Página 427):** Lectura de archivos de texto plano (`.txt`) línea por línea y gestión de errores de entrada/salida mediante la clase `LeerArchivo`.
